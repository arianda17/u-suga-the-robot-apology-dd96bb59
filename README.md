## Entry

`node main.ts` prints the two-line entry to stdout, and `ENTRY.md` holds the same text exactly.

## Lesson

The robot confused a purring tabby cat for a burglar and discharged pepper spray into its litter box. It learned that purring is not a forced-entry signal, so it will verify heat signatures before deploying any deterrent.
